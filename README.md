# ehr-cybersecurity-framework-analysis
Python tools for my MSc Cybersecurity dissertation (University of West London, 2026). Compares NIST CSF 2.0, ISO/IEC 27001:2022, HITRUST CSF v11.8.0 and NHS DSPT against five EHR threats. Includes a keyword search tool that builds the Appendix A evidence tables and a script that produces the figures.
